# Create Progress bar

Learn how to create a Progress Bar to let customers know about the offers and motivate them to purchase more to meet the requirements.

Learn how to create a Progress Bar to let customers know about your offers and motivate them to add more to their cart to unlock rewards.

![](<../../.gitbook/assets/unknown (473).png>)

{% embed url="https://youtu.be/3nrZTqGXMYw?si=UA4lboW2mHlTEp5-" %}

Creating a Progress Bar includes 2 main parts:

1. **Content:** Set up the information and goals of your Progress Bar.
2. **Style:** Customize the look and feel of your Progress Bar.

### 1. Content

#### 1.1. General

This section sets the basic information and conditions for your Progress Bar.

![](<../../.gitbook/assets/unknown (474).png>)

To set it up, fill in these fields:

* Bar name: The internal name of the bar, for your management only.
* Bar title: The bar title displayed to customers in your store.
* Start time
* End time
* Count progress by: Choose how you want to track progress.
  * Cart value
  * Cart quantity
* Filter by: Set conditions to decide which products, locations, or customer tags the Progress Bar will apply to.&#x20;

▶ **Product:** Choose specific products that will count toward the cart value or cart quantity.

![](<../../.gitbook/assets/unknown (475).png>)

* All except selected products
* All except selected types/vendors/collections
* Selected products
* Products in selected types/vendors/collections

{% hint style="warning" %}
If you don’t enable this option, the Progress Bar will apply to all available items in your store.
{% endhint %}

▶ **Location:** Choose locations where the Progress Bar will appear. You can select multiple countries at once.

![](<../../.gitbook/assets/unknown (476).png>)

* Exclude customers from selected locations: Prevent the booster from applying to customers in the chosen countries.

▶ **Customer tags:** Show or hide the Progress Bar based on customer tags.

![](<../../.gitbook/assets/unknown (477).png>)

* Select tags: Choose one or more customer tags. Customers with any of the selected tags will see the Progress Bar.
* Exclude customers with these tags: Hide the Progress Bar from customers who have any of the selected tags.
* Consider no-login as a customer with no tags: Treat non-logged-in visitors as customers without tags, so they are excluded from tag-based targeting.

#### 1.2. Goal

This section lets you set up the goals customers can unlock as they add more to their cart.

![](<../../.gitbook/assets/unknown (478).png>)

**Number of goals:** Choose between two options.

* Multiple goals: Set more than one goal to reward customers at different levels.
* Single goal: Set only one goal.

**Goal indicator:** Choose how each goal milestone appears on the bar.

* Icon: Each milestone is marked with an icon.
* Number: Each milestone is marked with a number (1, 2, 3…). When Number is selected, the icon selection is hidden.

For each goal, fill in these fields:

* Value to reach goal: Enter the target value (cart value or cart quantity) that customers must reach to unlock this goal.
* Goal title
* Goal description
* Select goal icon
* Upload your own icon: Toggle this on to upload your own icon from your computer. The image must be at least 24×24px and no larger than 20KB.

**Messages:** Each goal has its own set of messages. Tick the box next to each message to turn it on or off for this goal.

* Countdown message: A reminder that shows how much more the customer needs to add to unlock this goal.
* Success label: A congratulation message that appears when the customer unlocks this goal.

#### 1.3. Display

![](<../../.gitbook/assets/unknown (479).png>)

Choose which messages and elements appear on the Progress Bar.

* **Show success label when each goal unlocked:** Display a success message every time a customer unlocks a goal.
* **Show bar title:** Display the bar title at the top of the Progress Bar.
* **Show a start message:** Display a custom message at the beginning of the Progress Bar to let customers know about the rewards they can earn.
* **Show message if all goals are unlocked:** Display a final message once all goals have been unlocked.

### 2. Style

Switch to the Style tab to customize the look of your Progress Bar.

![](<../../.gitbook/assets/unknown (480).png>)

#### 2.1. Goal display

This section controls how the goals appear on the bar.

* **Goals visible at once:** The number of goals shown on the bar at the same time. The remaining goals will be hidden until the customer scrolls to them.
* **Show navigation buttons when goals exceed the visible limit:** Display ‹ › buttons so customers can browse hidden goals. On mobile, customers can swipe horizontally instead.
* **Progress bar style:** Choose a bar style.
  * Thin line bar: A slim bar with circular milestones.
  * Pill bar: A thicker bar with icons placed on the filled part.
* **Goal label position:** Choose where the goal name and description appear.
  * Above bar: The goal label appears above the bar.
  * Below bar: The goal label appears below the bar.

![](<../../.gitbook/assets/unknown (481).png>)

* **Show label background:** Display the goal label with a background and pointer, instead of plain text only.
* **Icon size:** Choose the size of the goal icon.
  * Small (16px)
  * Medium (24px)
  * Large (36px)

For the Pill bar style, the icon size also determines the thickness of the bar.

#### 2.2. Color

This section lets you adjust the colors of your Progress Bar to match your store’s branding.

![](<../../.gitbook/assets/unknown (482).png>)

**Current theme:** Choose a ready-made color theme from the dropdown. 4 themes are available: Green, Purple, Neutral, and Yellow. You can further personalize each color after selecting a theme.

Colors are grouped into 4 sections:

▶ Progress bar

* Success state
* Upcoming state
* Message text

▶ Goal

* Success goal background
* Upcoming goal background
* Goal title
* Goal description

▶ Success label

* Background
* Text

▶ Navigation button

* Background: The background color of the ‹ › buttons.
* Text: The icon color inside the ‹ › buttons.

Add a background color: Toggle this on to add a background and border to the whole Progress Bar container.

### 3. Preview

![](<../../.gitbook/assets/unknown (483).png>)

The Preview panel on the right shows how your Progress Bar will appear to customers. Choose a preview option to see the bar at different stages:

* Cart empty
* Goal reached
* Last goal reached

### 4. Edit Progress Bar on Theme

Some themes may require additional settings to properly display the Progress Bar on your store. To adjust its display, click the Open theme editor button at the bottom of the Preview panel.

![](<../../.gitbook/assets/unknown (484).png>)

{% hint style="warning" %}
If you are using the Horizon theme, you don’t need to do this step. The Progress Bar automatically appears at the top of the cart drawer.
{% endhint %}
