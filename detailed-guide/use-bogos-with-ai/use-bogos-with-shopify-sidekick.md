# Use BOGOS with Shopify Sidekick

Shopify Sidekick now connects with BOGOS, so you can check offer analytics, look up existing offers, and create new BOGOS offers directly from Sidekick chat.

Shopify Sidekick is Shopify's built-in AI assistant, available on all Shopify plans. To connect Sidekick with BOGOS, you need to have BOGOS: Free Gift Bundle Upsell installed on your store.

Using BOGOS with Shopify Sidekick includes **4 main capabilities:**

1. Grant Sidekick access to BOGOS.
2. Check BOGOS offer analytics.
3. Look up existing BOGOS offers.
4. Create new BOGOS offers.

### 1. Grant Sidekick Access to BOGOS

The first time you ask Sidekick to work with BOGOS, it will ask for your permission to access the app.

![](<../../.gitbook/assets/unknown (395).png>)

Choose one of the following options:

* **Yes:** Grant access for this action only. Sidekick will ask again next time.
* **Yes, and don't ask again:** Grant access permanently, so Sidekick won't ask again.
* **No:** Deny access for this action.
* **Other:** Type your own response.

You only need to grant access once if you select "Yes, and don't ask again."

### 2. Look Up Existing BOGOS Offers

You can ask Sidekick to list your existing BOGOS offers, grouped by offer family (Gift, Bundle, Upsell, Discount). Each offer shows its name, type, and start date, and Sidekick will flag whether it's currently active or deactivated.

![](<../../.gitbook/assets/unknown (396).png>)

Example prompts:

* "Show me all my existing BOGOS offers."
* "List all my Gift offers."
* "Which BOGOS offers are currently deactivated?"

From there, you can ask Sidekick to dig into performance for any specific offer, or open it directly in BOGOS to edit or reactivate.

### 3. Check BOGOS Offer Analytics

You can ask Sidekick to pull performance data for any of your BOGOS offers.

![](<../../.gitbook/assets/unknown (397).png>)

#### What Sidekick can pull:

**For all offer families (Gift, Bundle, Upsell, Discount):**

* Total sales/revenue
* Order count
* Average order value (AOV)

**For Bundle, Upsell, and Discount offers, Sidekick can also pull:**

* Units sold
* Views
* Add-to-cart count
* Average add-to-cart value

#### How you can slice the data:

* By offer family (e.g., all your bundles).
* By a specific offer (e.g., the Blush BOGO offer).
* Across all families at once for a full overview.

#### Time ranges available:

* A custom date range (any start and end date).
* Preset periods: 1, 7, 30, or 90 days.

Example prompts:

* "Show me the sales, order count, and average order value for the Blush BOGO offer over the last 30 days."
* "How are all my bundles performing this week?"
* "Give me a full overview of all BOGOS offers for the last 90 days."

Newly created offers need around 24 hours for data to populate, so figures will show zeros until then.

### 4. Create New BOGOS Offers

![](<../../.gitbook/assets/unknown (398).png>)

Sidekick can create new offers across all 4 BOGOS offer families:

* Gift offers (e.g., BOGO, Free Gift).
* Bundle offers (e.g., Classic Bundle, Bundle as a Product).
* Upsell offers (e.g., Frequently Bought Together, Checkout Upsell).
* Discount offers (e.g., Volume Discount, Cart Discount).

#### How it works:

* Type a plain-language prompt describing the offer you want (e.g., "Create a BOGOS Buy 1 Get 1 offer for Blush").
* Sidekick may ask clarifying questions, such as which product variant the offer should apply to.
* Sidekick opens the matching BOGOS offer builder, pre-filled with your setup (offer name, title, trigger product, gift, discount value, etc.).
* Review and adjust the details in the builder (e.g., widget display, sub-conditions, tiers).
* Click Save to publish the offer. Save = Publish, so the offer goes live once saved.

Example prompts:

* "Create a BOGOS Buy 1 Get 1 offer for Blush. When a shopper purchases 1 Blush, automatically add 1 additional Blush as a free gift."
* "Set up a Frequently Bought Together offer for my skincare collection."
* "Create a 10% cart discount for orders over $100."

{% hint style="warning" %}
As the limitation of the current synced data, some setup may have mistakes. You always need to review the offer carefully before publishing.<br>
{% endhint %}

Sidekick pre-fills the offer as an unsaved draft in the BOGOS builder. Nothing goes live until you review and click Save.

### Best Practices for Writing Prompts

* Be specific: state the offer type, product/collection, quantity, and discount value clearly.
* Use short, direct sentences to avoid confusion.
* Include extra details like start/end dates or campaign goals when relevant.
