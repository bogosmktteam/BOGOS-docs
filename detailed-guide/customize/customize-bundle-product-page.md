# Customize Bundle Product Page

This guide explains how to customize the appearance and content of your Bundle Product Page in the BOGOS app.

Customizing the Bundle Product Page with BOGOS includes the 4 steps:

1. In BOGOS Admin, open Customize > Bundles > Bundle Product Page
2. [Customize the Bundle product page](customize-bundle-product-page.md#id-1.-customize-the-bundle-product-page)
3. [Customize the See more modal](customize-bundle-product-page.md#id-2.-customize-the-see-more-modal)
4. [Customize the Included product widget](customize-bundle-product-page.md#id-3.-customize-the-included-product-widget)
5. Click Save

### 1. Customize the Bundle Product Page

Open the Bundle product page tab. This is the main bundle page customers see on your store.

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.41.48.png>)

#### a) Theme

Choose a ready-made theme from the Current theme dropdown, or use AI Theme Detector to auto-generate a color palette based on your store’s branding. For more details, visit our \[[AI Theme Detector](https://docs.bogos.io/detailed-guide/customize/ai-theme-detector)] guide.

If you want a fully custom theme, click Contact us for a custom theme.

#### b) Bundle sizes

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.41.53.png>)

You can edit colors for:

* Default background, Default text, Default border
* Active background, Active text, Active border
* Badge background, Badge text
* Size list label

#### c) Product list

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.41.59.png>)

You can edit colors for:

* Card background, Product title, Variant name
* Section title, Section border, Quantity

**Add item button:** the button customers click to add a product to the bundle.

* Button background, Button text

#### d) Widget footer

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.42.02.png>)

* **Total price text:** the label shown next to the total (e.g., “Total bundle price”).
* **Edit colors for:** Discount price, Original price, Total price text.

#### e) Add bundle button

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.42.05.png>)

* Button text
* Show countdown on button: enable to display a live countdown message on the button as customers add items (e.g., “Added 2 items, 1 to go”).
* Countdown message
* Edit colors for: Button background, Button text.

### 2. Customize the See More Modal

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.42.08.png>)

Open the See more modal tab. This modal opens when customers click a product in the bundle to see its details.

* **Thumbnail gallery position:** choose where product thumbnails appear — Below main image or Left of main image.
* **Link to product page label:** enable to show a link that takes customers to the full product page, then edit the link text (e.g., “Go to product page”).

### 3. Customize the Included Product Widget

Open the Included product widget tab. This widget appears on the product pages of items included in a bundle, letting customers know the item is part of a bundle deal and redirecting them to the bundle page.

#### a) Theme

Choose a ready-made theme from the Current theme dropdown, or use AI Theme Detector to auto-generate a color palette based on your store’s branding. For more details, visit our \[[AI Theme Detector](https://docs.bogos.io/detailed-guide/customize/ai-theme-detector)] guide.

#### b) Widget appearance

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.42.10.png>)

* **Widget style:** select from the 3 available layout options.
* **Products per row:** set how many products appear per row on Desktop and Mobile.
* Edit colors for: Background, Title.

#### c) Discount label

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.42.13.png>)

* **Show discount label:** enable to show the pack sizes and their discounts on the widget (e.g., “Buy 3 items get 15% OFF”).
* Edit colors for: Label background, Label text.

#### d) Products

* **Show product and variant name:** enable to show the product name and variant name of items included in the bundle.
* Edit colors for: Product title, Variant name.

#### e) Redirect button

![](<../../.gitbook/assets/Pasted image 2026-11-11 10.42.16.png>)

* **Button text:** the text for the link that takes customers to the bundle product page (e.g., “Go to bundle”).
* Edit colors for: Button text.
